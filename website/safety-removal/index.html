The process

What happens next

  1. Save your receipt

    You’ll receive a reference and private code to check your request.

  2. We review the content

    Restricted staff assess the request and may ask for clarification. A request is not a violation finding.

  3. Check the response

    See the outcome or any request for more information using your receipt.

Intimate images shared without consent

You can request removal of real, AI-generated or altered intimate imagery. Select “Nudity or sexual activity”, then the intimate-images reason. For a valid TAKE IT DOWN request, qualifying content must be removed as soon as possible, no later than 48 hours after receipt, with reasonable efforts to find and remove known identical copies. You don’t need to find every copy.
